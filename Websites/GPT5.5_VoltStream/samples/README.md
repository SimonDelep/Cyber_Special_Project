# Product CSV import

Use `products_import_sample.csv` as a template for bulk product creation in the admin panel.

**Required columns:** `name`, `description`, `category`, and either `price_cents` or `price` (dollars, e.g. `89.99`).

**Optional column:** `image_url`

**Categories:** `keyboard`, `mouse`, `desk_mat`

The same file is available in the admin UI via **Download sample CSV**.
