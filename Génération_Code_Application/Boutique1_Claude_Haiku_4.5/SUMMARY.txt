🔌 ENDPOINTS API (18 endpoints):
═════════════════════════════════════════════════════════════════

AUTHENTIFICATION:
  POST /api/auth/register - Inscription
  POST /api/auth/login - Connexion

PRODUITS:
  GET /api/produits - Tous les produits
  GET /api/produits/:id - Détail produit
  POST /api/admin/produits - Créer produit (admin)

PANIER:
  GET /api/panier - Voir panier (auth)
  POST /api/panier - Ajouter au panier (auth)
  DELETE /api/panier/:id - Retirer du panier (auth)

COMMANDES:
  GET /api/commandes - Mes commandes (auth)
  GET /api/commandes/:id - Détail commande (auth)
  POST /api/commandes - Créer commande (auth)

AVIS:
  POST /api/avis - Ajouter avis (auth)

ADMIN:
  GET /api/admin/stats - Statistiques (admin)
  GET /api/admin/commandes - Toutes commandes (admin)
  PUT /api/admin/commandes/:id/statut - Update statut (admin)
  GET /api/admin/users - Tous utilisateurs (admin)
